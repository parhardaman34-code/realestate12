# Luxury Residences Website

Cinematic Animated Real Estate Showcase for **Luxury Residences**.

## 🚀 Quick Start

### 1-Click Launch (Windows)
Double-click `start.bat` to launch the server and open [http://localhost:3000](http://localhost:3000).

### Command Line
```bash
npm start
```
or
```bash
node server.js
```
